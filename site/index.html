Fenn Browser

Fenn is a browser for Windows built on Firefox's engine, with a native WinUI 3 window around it: the tab strip, navigation toolbar, address bar and menus are Windows controls. Web content, add-ons, security and browser behaviour remain Firefox's.

Fenn is in development and has not been released. There is no download yet.

What it is

  • Firefox's Gecko engine and browser logic, with a native Windows 11 shell around it that follows your Windows theme, light or dark, and high contrast.
  • A narrow, minimal default layout with native tabs, tab groups, a native address bar and a toolbar you can customise by dragging buttons.
  • An optional built-in ad blocker, off by default.
  • A distribution with no Mozilla partner codes in search, no sponsored suggestions, shortcuts or stories by default, and no telemetry upload, crash reporter or studies.
  • Distributed as an MSIX package, planned both through the Microsoft Store and as a download from this website, with updates through Windows rather than Firefox's updater.
