Fenn Browser

Fenn is a browser for Windows built on Firefox's engine, with the tab strip, toolbar and address bar being moved to native WinUI 3 controls. Web content, add-ons and browser behaviour remain Firefox's.

Fenn is in development and has not been released. There is no download yet.

What it is

  • Firefox's Gecko engine and browser logic, with a native Windows 11 shell around it.
  • A distribution with no Mozilla partner codes in search, no sponsored suggestions, shortcuts or stories by default, and no telemetry upload, crash reporter or studies.
  • Distributed as an MSIX package, planned through the Microsoft Store.

Source and licence

Fenn is built from Mozilla's Firefox source. Modified Mozilla files remain under the Mozilla Public License 2.0, and Fenn's own code is released under the same licence. The source is public at github.com/fennbrowser/fenn.
